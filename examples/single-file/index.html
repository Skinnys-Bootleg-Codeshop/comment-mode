Comment mode: single-file example

This whole example is one HTML file. Open it directly from disk (double-click it, or drag it into a browser tab) and it works: no server, no build step, no dependencies beyond the browser itself.

Everything comment mode needs is the one script tag below. Turn on comment mode with the button in the corner, then tap any sentence on this page to leave a comment. Comments are stored in this browser's localStorage, so they're private to you and this machine, and they'll still be here the next time you open this file.

To use this in your own project: copy comment-mode.js from the root of this repository into your project alongside your HTML file, then add the same one-line script tag this page uses below, pointing at your own copy. That's the whole setup; everything else here is page content.
