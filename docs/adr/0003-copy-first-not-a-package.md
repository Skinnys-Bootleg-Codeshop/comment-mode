# Copy first, not a package

Comment mode is released as a self-contained module with worked examples (a single HTML file, and Next.js with Upstash) that people copy into their project and change, the way shadcn/ui works. It is not published as an installable package yet. Portfolio copies it in too. We chose this because a package means a stable API, versioning and compatibility promises before anyone but Charles uses it; keeping the module self-contained means publishing it later is a small step.
